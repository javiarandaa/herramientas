# Mis comandos de terminal y Git

| Comando | Para qué sirve |
|---|---|
| `pwd` | Saber en qué carpeta estoy |
| `ls` | Listar los archivos de la carpeta |
| `cd` | Cambiar de carpeta |
| `mkdir` | Crear una carpeta |
| `git init` | Convertir una carpeta en repositorio |
| `git add` | Preparar cambios para el commit |
| `git commit -m` | Guardar una foto de los cambios con un mensaje |
| `git push` | Subir mis commits a GitHub |
| `git pull` | Bajar de GitHub los commits que no tengo |
| `git clone` | Copiar un repositorio completo de GitHub |
